# Frontend

Frontend project built with **React 18**, **Vite 6**, **Tailwind CSS**, **Radix UI**, and **shadcn/ui**.  
This project provides both **Admin** and **Client** interfaces for managing an e-commerce platform.

## 🧱 Tech Stack

- [React 18](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.dev/)
- [Radix UI](https://www.radix-ui.com/)
- [Lucide Icons](https://lucide.dev/)
- [React Router v7](https://reactrouter.com/)
- [Axios](https://axios-http.com/)
- [Recharts](https://recharts.org/) — charting library
- [Embla Carousel](https://www.embla-carousel.com/) — lightweight carousel
- [React OAuth Google](https://www.npmjs.com/package/@react-oauth/google)
- [react-facebook-login](https://www.npmjs.com/package/react-facebook-login)

## 📦 Installation

```bash
npm install
```

## 🚀 Development

```bash
npm run dev
```

Runs the development server at http://localhost:5173.

## 📦 Build

```bash
npm run build
```

Builds the project for production.

## 🔍 Preview

```bash
npm run preview
```

Serves the production build locally.

## 🧹 Lint

```bash
npm run lint
```

Runs ESLint to check for linting issues.

## ✨ Features

- ⚙️ **Admin dashboard**: Manage products, categories, orders, and customers.
- 🛒 **Client interface**: Product listing, cart, wishlist, checkout, and profile management.
- 🌐 **OAuth login**: Google and Facebook login integration.
- 🎨 **shadcn/ui + Radix UI**: Accessible, themeable, and reusable component primitives.
- 📊 **Data visualization**: Beautiful charts using Recharts.
- 🎠 **Carousel**: Product sliders powered by Embla Carousel.
- 📱 **Responsive design**: Mobile-friendly layout using Tailwind CSS.
